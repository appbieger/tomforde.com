# Replace inline success message styles with proper CSS classes

## Overview

Move the contact form success message inline styles to the SCSS file and improve visual consistency with the design system

## Rationale

The success message in contact-form.jekyll.html (lines 15-20) uses inline styles with hardcoded colors (#d4edda, #c3e6cb, #155724) that don't match the site's color scheme variables. This creates visual inconsistency and makes maintenance harder.
